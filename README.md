## 저장소 구조

페이지는 **조각 파일을 합쳐서** 만듭니다. 사진은 빌드할 때 base64로 심기 때문에
`index.html` 한 장만 있으면 어디서든 열립니다.

```
_제작도구/
  소스-1-스타일.html    스타일 (팔레트·타이포·레이아웃)
  소스-2-스타일.html    스타일 (컴포넌트)
  소스-3-히어로.html    히어로 + 01~04 (사례·챗GPT 비교·변화·걱정 Q&A)
  소스-4-커리큘럼.html  05~07 (시간표·밤 8시·왜 충주에서)
  소스-5-준비물-강사.html  08~10 (준비물·강사·수료 후)
  소스-6-예약.html      11~12 (일정·FAQ) + CTA·푸터·신청 링크
  빌드.js               위 조각을 합치고 사진을 심어 index.html 을 만든다
  포스터-소스.html      홍보물(A4 포스터 + SNS 카드 6장) 편집용 원본
  포스터빌드.js         QR 과 클로드 코드 표식을 심어 홍보물/포스터.html 을 만든다
  qr-네이버예약.svg     신청 링크 QR (25×25 path, 색은 CSS 가 정한다)
  아이콘-클로드코드.svg 화면 모사 블록에 쓰는 표식 (직접 그린 sunburst)
사진/                   페이지에 쓰인 사진 6장
홍보물/                 포스터 PDF · SNS 카드 PNG · 채널별 홍보 문구
index.html              빌드 결과물 (GitHub Pages 가 서비스하는 파일)
```

### 다시 만들기

```bash
node "_제작도구/빌드.js"
```

**문구나 스타일은 `_제작도구/소스-*.html` 에서 고칩니다.** `index.html` 을 직접 고치면
다음 빌드 때 사라집니다. 빌드는 몇 번을 돌려도 결과가 같습니다.

신청 링크는 `소스-6-예약.html` 맨 아래 `BOOKING_URL` 한 곳에만 있습니다.

## 홍보물

`홍보물/` 에 인쇄용 포스터와 SNS 카드, 채널별 문구가 들어 있습니다.
페이지와 같은 아이덴티티(검은 바탕 · Black Han Sans · 직각)로 맞춰 뒀어요.

| 파일 | 용도 |
|---|---|
| `충주클로드코드워크숍_포스터.pdf` | A4 한 장. 가게·게시판 부착용. 신청 QR 포함 |
| `카드-1..6.png` | SNS 카드 1080×1350 (표지 / 화면 / 만들어지는 것 / 서울 대비 / 시간표 / 준비물·신청) |
| `포스터.html` | 위 일곱 장의 원본. 화면에서 보고 인쇄까지 된다 |
| `홍보문구.md` | 카톡·직장인 채널·문자·인스타·블로그·네이버예약 문구 |

```bash
node "_제작도구/포스터빌드.js"
```

PDF 와 PNG 는 브라우저를 거쳐야 합니다 — 방법은 [`제작노트.md`](제작노트.md) 에 적어 뒀어요.

## 쓰셔도 됩니다

구조와 코드는 자유롭게 가져다 쓰셔도 됩니다. 지역에서 비슷한 걸 여시는 분이라면
소스 조각을 그대로 복사해서 내용만 바꾸시면 됩니다.

다만 **`사진/` 폴더의 사진에는 참가자와 진행자가 찍혀 있어서 재사용할 수 없습니다.**
가져다 쓰실 때는 사진을 빼고 쓰시거나 직접 찍은 것으로 바꿔 주세요.
