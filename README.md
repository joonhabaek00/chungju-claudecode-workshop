## 저장소 구조

페이지는 **조각 파일을 합쳐서** 만듭니다. 사진은 빌드할 때 base64로 심기 때문에
`index.html` 한 장만 있으면 어디서든 열립니다.

```
_제작도구/
  소스-1-스타일.html    스타일 (팔레트·타이포·레이아웃)
  소스-2-스타일.html    스타일 (컴포넌트)
  소스-3-히어로.html    히어로 + 01~04 (사례·챗GPT 비교·변화·걱정 Q&A)
  소스-4-커리큘럼.html  05~07 (시간표·밤 8시·왜 충주에서)
  소스-5-준비물-강사.html  08~10 (준비물·강사·수료 후)
  소스-6-예약.html      11~12 (일정·FAQ) + CTA·푸터·신청 링크
  빌드.js               위 조각을 합치고 사진을 심어 index.html 을 만든다
사진/                   페이지에 쓰인 사진 6장
index.html              빌드 결과물 (GitHub Pages 가 서비스하는 파일)
```

### 다시 만들기

```bash
node "_제작도구/빌드.js"
```

**문구나 스타일은 `_제작도구/소스-*.html` 에서 고칩니다.** `index.html` 을 직접 고치면
다음 빌드 때 사라집니다. 빌드는 몇 번을 돌려도 결과가 같습니다.

신청 링크는 `소스-6-예약.html` 맨 아래 `BOOKING_URL` 한 곳에만 있습니다.
